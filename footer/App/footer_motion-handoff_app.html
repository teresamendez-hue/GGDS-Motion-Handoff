Hace click en el Field Text para abrir el teclado y disparar el motion del Footer. Tambien podes usar los botones Abrir / Cerrar / Reset. Blur del field cierra el teclado. Si Overlay inicial esta desmarcado, el Footer pasa a Overlay/True al enfocar.

Este preview simula el spring en el navegador (mass / stiffness / damping del Token Mapping). No es Flutter. Los valores que implementas son los del Token Mapping.

State: idle · overlay false

Implementacion Dart (Flutter)

const _footerRepositionSpring = SpringDescription(
  mass: 1.0,
  stiffness: 300.0,
  damping: 28.0,
);

// Preferido: viewInsets nativo
Widget buildFooter(BuildContext context) {
  final bottomInset = MediaQuery.viewInsetsOf(context).bottom;
  final overlay = _resolveOverlay(context, bottomInset > 0);

  return AnimatedPadding(
    padding: EdgeInsets.only(bottom: bottomInset),
    duration: const Duration(milliseconds: 300),
    curve: Curves.easeOut,
    child: _FooterSurface(overlay: overlay),
  );
}
